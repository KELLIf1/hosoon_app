# 🕌 الحصون الخمسة

تطبيق Flutter لحفظ القرآن الكريم، يحوّل طريقة **"الحصون الخمسة"** (د. سعيد أبو العلا حمزة) إلى محرك جدولة تلقائي بسيط.

المدخل الوحيد المطلوب من المستخدم: **معدل حفظ أسبوعي واحد** (بوحدة أرباع الحزب). من هذا الرقم يبني التطبيق خطة يومية كاملة تلقائيًا، بلا أي إعدادات إضافية.

---

## 📖 الحصون الخمسة

| #   | الحصن            | الوصف                                  |
| --- | ---------------- | -------------------------------------- |
| 1   | الحفظ الجديد     | حفظ المقدار الجديد المقرر لليوم        |
| 2   | مراجعة القريب    | مراجعة ما تم حفظه في الأيام الأخيرة    |
| 3   | مراجعة البعيد    | مراجعة الأجزاء القديمة المحفوظة سابقًا |
| 4   | التحضير          | تحضير المقطع الجديد قبل حفظه           |
| 5   | القراءة المستمرة | قراءة ورد يومي من القرآن كاملًا        |

---

## ✨ الفكرة الأساسية

- **إدخال واحد فقط**: المستخدم يختار معدله الأسبوعي من قائمة جاهزة (pills) عند أول تشغيل.
- **خطة مشتقة تلقائيًا**: لا تُخزَّن الخطة اليومية كبيانات ثابتة، بل تُحسب لحظيًا (Derived State) من معادلة:

  ```
  lastMemorizedQuarterIndex + weeklyMemorizationRate
  ```

  هذا يمنع تضارب البيانات، ويسمح بحساب خطة أي يوم — ماضٍ أو مستقبل — دون تخزين إضافي.

- **تفاعل بثلاث حالات لكل يوم**:

| نوع اليوم    | تُعرض الخطة؟  | قابلة للتفاعل؟                    |
| ------------ | ------------- | --------------------------------- |
| مستقبلي      | ✅ نعم        | ❌ اطلاع فقط                      |
| اليوم الحالي | ✅ نعم        | ✅ التفاعل الفعلي (تأشير الإنجاز) |
| ماضٍ         | ✅ نعم (كسجل) | ❌ للتاريخ فقط                    |

---

## 🖥️ الشاشات

1. **Onboarding** — سؤال واحد فقط: اختيار المعدل الأسبوعي.
2. **Daily Card** — شريط تواريخ + 5 بطاقات قابلة للطي (حصن لكل بطاقة) + شارة Streak.
3. **Hosn Detail** — عرض موسّع لحصن واحد مع زر "تم الإنجاز".
4. **Weekly Log** — جدول 7×5 (أيام × حصون) يوضح بالضبط أي حصن أُنجز أو فات، مع إحصائيات.
5. **Progress Map** — نسبة التقدم الكلية عبر 60 نقطة تمثل الأحزاب الستين.
6. **Settings** — إعدادات عامة وزر Reset (أحمر، لأنه إجراء تدميري).

## 🏗️ المعمارية

**Functional Core + Simple Layers** — بديل مبسّط عن معمارية Feature-First MVVM الكاملة، مناسب لتطبيق بمصدر بيانات محلي واحد (Hive) ومستخدم واحد.

**القاعدة الصارمة الوحيدة**: لا imports لـ Hive أو Flutter UI داخل `core/engine` أبدًا.

### شرح وظيفة كل ملف

#### `core/constants/` — ثوابت خام، بلا منطق

| الملف                  | الوظيفة                                                                                            |
| ---------------------- | -------------------------------------------------------------------------------------------------- |
| `app_colors.dart`      | القيم الخام للألوان فقط (`#E8ECF0`, `#1A2B4A`, `#7EC8E3`...)، بلا أي منطق أو حسابات.               |
| `app_text_styles.dart` | تعريف أنماط النص (أحجام، أوزان الخط، خط Inter) و `TextTheme` الموحّد للتطبيق.                      |
| `quran_constants.dart` | الثوابت الرياضية الثابتة للقرآن: 240 ربع، 60 حزب، 20 صفحة لكل حزب... تُستخدم كمرجع في كل الحسابات. |

#### `core/engine/` — المنطق الصرف (Pure Dart، بلا Hive أو Flutter)

**`models/`** — كائنات البيانات فقط، بلا سلوك معقّد:

| الملف                     | الوظيفة                                                                                              |
| ------------------------- | ---------------------------------------------------------------------------------------------------- |
| `hosn_type.dart`          | `enum` يعرّف الحصون الخمسة (الحفظ الجديد، مراجعة القريب، مراجعة البعيد، التحضير، القراءة المستمرة).  |
| `day_progress.dart`       | يمثّل حالة إنجاز يوم واحد: خريطة `Map<HosnType, bool>` توضّح أي حصن أُنجز في ذلك اليوم.              |
| `day_plan.dart`           | الخطة اليومية الناتجة عن المحرك — أي المقدار المطلوب حفظه/مراجعته لكل حصن في يوم معيّن.              |
| `memorization_state.dart` | الحالة الكلية للحفظ: آخر ربع تم حفظه (`lastMemorizedQuarterIndex`) بالإضافة للمعدل الأسبوعي المختار. |

**ملفات المنطق:**

| الملف                    | الوظيفة                                                                                                                                                                            |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hosn_engine.dart`       | **قلب التطبيق.** كل الدوال الحسابية الصرفة (Pure Functions) التي تحوّل `MemorizationState` + تاريخ مطلوب إلى `DayPlan` كامل. لا تخزين، لا تأثيرات جانبية — فقط دخل → معالجة → خرج. |
| `streak_calculator.dart` | حساب سلسلة الإنجاز المتتالية (`calculateStreak`) وتحديد الحصن الأكثر فوتًا (`mostMissedHosn`) بناءً على سجل الأيام السابقة.                                                        |

#### `data/` — الطبقة الوحيدة التي "تعرف" Hive

| الملف                        | الوظيفة                                                                                                                                                                 |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hive_boxes.dart`            | تعريف أسماء وهياكل صناديق (boxes) Hive المستخدمة في التخزين المحلي.                                                                                                     |
| `local_storage_service.dart` | الكلاس الوحيد في كامل التطبيق الذي يستورد Hive مباشرة. يغلّف كل عمليات القراءة/الكتابة، ويحوّل بين نماذج `core/engine` وصيغة التخزين (toJson/fromJson أو TypeAdapters). |

#### `providers/` — الربط عبر Riverpod

| الملف                              | الوظيفة                                                                                                                      |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `storage_provider.dart`            | يوفّر نسخة من `LocalStorageService` لبقية الـ providers، بدون أن تحتاج الواجهة معرفة تفاصيل التخزين.                         |
| `memorization_state_provider.dart` | يحمّل ويحدّث `MemorizationState` (آخر ربع محفوظ + المعدل الأسبوعي) ويُبقيها متزامنة مع التخزين.                              |
| `today_plan_provider.dart`         | يستدعي `hosn_engine.dart` لحساب خطة اليوم الحالي لحظيًا اعتمادًا على `MemorizationState`، دون تخزين الخطة نفسها.             |
| `daily_log_provider.dart`          | يدير سجل `DayProgress` لكل الأيام (الحالي والماضي)، ويمنع أي محاولة تعديل لغير اليوم الحالي وفق قاعدة `DayInteractionState`. |

#### `features/` — الشاشات (Widgets فقط)

كل مجلد يمثّل شاشة مستقلة ولا يزال فارغًا (يحتوي حاليًا على `.gitkeep` فقط لتثبيت الهيكل في Git):

| المجلد          | الشاشة المرتبطة                                  |
| --------------- | ------------------------------------------------ |
| `onboarding/`   | Screen 1 — اختيار المعدل الأسبوعي عند أول تشغيل. |
| `daily_card/`   | Screen 2 و 3 — البطاقة اليومية وتفاصيل كل حصن.   |
| `weekly_log/`   | Screen 4 — جدول المراجعة الأسبوعية (7×5).        |
| `progress_map/` | Screen 5 — خريطة التقدم الكلية (60 نقطة).        |
| `settings/`     | Screen 6 — الإعدادات وزر Reset.                  |

#### جذر `lib/`

| الملف       | الوظيفة                                                                            |
| ----------- | ---------------------------------------------------------------------------------- |
| `app.dart`  | نقطة تجميع التطبيق: تهيئة `MaterialApp`/`ProviderScope`، والتنقل بين الشاشات الست. |
| `main.dart` | نقطة الدخول (`main()`)، تهيئة Hive وفتح الصناديق قبل تشغيل `runApp`.               |
